# Session Manager

A lightweight static session management app built with plain HTML, CSS, and JavaScript.

## Features

- Create sessions with title, date, duration, status, and notes
- Search through saved sessions
- Toggle session status and delete sessions
- Persist data in the browser with localStorage
- Ready to deploy on Vercel as a static site

## Local preview

Open index.html directly in a browser, or serve the folder with any static server.

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Vercel will detect the static site and deploy it automatically.
